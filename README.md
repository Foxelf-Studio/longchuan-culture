## 效果示例

### 问：龙川县有多少个镇？

```
龙川文化    ❯ 龙川下辖 24 个镇，县政府驻老隆镇。

            老隆镇、鹤市镇、麻布岗镇为三大中心镇。
            铁场镇面积最大（251.93km²），登云镇最小（67km²）。

            其中有几个镇特别值得一提：
            · 佗城镇 — 秦汉岭南第一古镇，赵佗首任县令治所
            · 田心镇 — 霍山所在地，畲族聚居，八宝鱼生之乡
            · 黎咀镇 — 省级非遗手擎木偶传承地
            · 贝岭镇 — "十万挑夫上赣南"发源地

            你想了解哪个镇的特色文化？
```

### 问：铁场镇的 IP 形象核心元素是什么？

```
龙川文化    ❯ 铁场镇拥有双 IP：铁壳龙 + 茶丫。

            铁壳龙 — 承铁匠精神与霍龙传说
            · 铁衣裹稻：铁匠精神与农耕融合
            · 龙鳞沾霍山霜：霍山自然风情
            · 呼应"铁场"之名——明朝 5 户铁匠打铁，"铁厂"谐音为铁场

            茶丫 — 载红色魂与产业兴
            · 客家白布蓝花头巾绣油茶
            · 竹篓铭刻"居仁"：居仁故里红色记忆
            · 背篓油茶果：产业生机

            一承匠造根脉，一载产业新生。
```

### 问：龙川有什么非遗项目？

```
龙川文化    ❯ 龙川拥有 8 项非物质文化遗产：

            省级（2项）
            · 手擎木偶（黎咀镇）— 手工操控木偶，客家戏曲活化石
            · 龙川杂技 — 柔术、顶技，曾赴美日新加坡演出

            市级（3项）
            · 佗城豆腐丸 · 客家山歌 · 打马灯

            县级（3项）
            · 车田豆腐 · 雅寄酒（紫市镇） · 八宝鱼生（田心镇）

            此外还有 9 处文物保护单位，包括北宋塔丰下塔（省保）、
            秦代越王井、新石器时代坪岭头遗址等。
```

### 问：推荐一条龙川的文化旅游路线

```
龙川文化    ❯ 推荐「千年古镇·秦汉文化之旅」：

            佗城镇 → 老隆镇 → 登云镇

            佗城 | 秦汉岭南第一古镇、越王井、龙川学宫
            老隆 | 福建会馆、进士文化、烟火夜市
            登云 | 古驿儒风、品尝特色鸡肉醋

            适合历史文化爱好者，半天到一天行程。

            或者你对霍山山水/红色记忆/东江客家乡愁更感兴趣？
            另有 5 条主题路线可选。
```
